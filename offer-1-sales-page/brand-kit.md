# Brand kit - Game Tape (from Game Tape Brand Guidelines.pdf, Nov 20 2026)

Name: Game Tape
Vibe: raw, real, hit-record energy. Bold black type, one hard red, lots of white. Straight talk, no guru gloss.

Source: Game Tape Brand Guidelines.pdf (colors page: RED #D30805, BLACK #101017, WHITE #FFFFFF; typeface page: Archivo Black headings, Poppins subtext). The guide has only 3 colors, so the soft grey, the light red tint and the light red for dark sections are derived (tints/shades of the brand colors), as the template asks.

## Colors (hex)
- #D30805 Game Tape red
- #101017 Game Tape black (T on light)
- #FFFFFF white (T)
- #F4F2EF warm light grey (derived: alternate section band)
- #FFD6D3 light red tint (derived: highlighter)
- #FF6B63 light red (derived, T: secondary text on black, because brand red on black is only 3.4:1)

## Role map
- bg: #FFFFFF (white)
- paper: #FFFFFF
- ink: #101017
- ink-soft: #4A4A55 (derived grey, 8.7:1 on white)
- accent: #D30805 (red: shadows, handwritten notes, numbers)
- soft: #FFD6D3 (light red tint: highlighter marks, soft shadows)
- hi: #D30805 (red: button fill, check marks)
- on-hi: #FFFFFF (white button text, 5.5:1)
- sand: #F4F2EF (warm light grey band)
- dark: #101017
- on-dark: #FFFFFF
- on-dark-2: #FF6B63

## Contrast checks
- ink on white / grey band: 18.9:1 / 17.0:1 pass
- ink-soft on white: 8.7:1 pass
- white on red button: 5.5:1 pass
- red on white (headline accents, numbers): 5.5:1 pass
- white on black: 18.9:1 pass; light red on black: 6.8:1 pass
- brand red #D30805 on black: 3.4:1, large headline words only (never body text on dark)

- Standard: Lato
